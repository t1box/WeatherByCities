# Weather by Cities

Скрипт читает список городов из файла `cities.txt` и для каждого уникального города получает текущую погоду через сервис [wttr.in](https://wttr.in). Для каждого города выводятся страна и температура в градусах Цельсия. Затем города группируются по странам, и по каждой стране выводятся количество городов, средняя, минимальная и максимальная температура.

## Запуск

Нужен Python 3.7 или новее. Файл `cities.txt` должен лежать в той же папке, что и скрипт.

```
python weather.py
```

В `cities.txt` один город на строку. Пустые строки и повторы пропускаются.

## Используемые модули

Только стандартная библиотека, сторонние пакеты не нужны:

- `json` — разбор ответа API;
- `urllib.request`, `urllib.parse` — HTTP-запросы и кодирование названия города в URL;
- `dataclasses` — модель `WeatherData` (город, температура, страна).

## Пример вывода

```
Погода по городам:
Moscow, Russia +12 °C
Khabarovsk, Russia +1 °C
Saint-Petersburg, Russia +9 °C
Vienna, Austria +16 °C
Izhevsk, Russia +5 °C
Perm, Russia +6 °C
NhaTrang, Vietnam +25 °C
Villach, Austria +7 °C

Статистика по странам:
Russia — 5 cities, avg: +7 °C, min: +1 °C, max: +12 °C
Austria — 2 cities, avg: +12 °C, min: +7 °C, max: +16 °C
Vietnam — 1 cities, avg: +25 °C, min: +25 °C, max: +25 °C
```

Если для города не удалось получить данные, скрипт выводит сообщение об ошибке и переходит к следующему.
